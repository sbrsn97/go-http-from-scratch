# go-http-from-scratch

A from-scratch HTTP/1.1 server written in Go to explore TCP, HTTP parsing, connection handling, concurrency, and networking fundamentals without using `net/http`.

## Goals

- Understand TCP connection lifecycle and byte streams
- Implement HTTP/1.1 request parsing and response serialization
- Learn Go networking and concurrency primitives
- Build a small, well-tested server suitable for a portfolio project

## Status

Early development. Currently implementing the TCP server foundation.
